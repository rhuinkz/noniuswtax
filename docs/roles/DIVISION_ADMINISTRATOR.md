# Division Administrator — Step-by-Step Manual

## Account and navigation
Sign in over HTTPS; complete first-login password and recovery-email setup. Use **Dashboard, Division Action Center, Transactions, Transaction Periods, Suppliers, ATC Master, Schools, Reports, Administration, My Account**. **System Settings** is reserved for the Project Owner.

## Setup
1. Under **Administration**, verify Division payor name, address, TIN, representative and designation.
2. Register participating schools with code, name, address and designated signatory. The system creates a linked School User with a one-time temporary password for new schools.
3. Configure the **ATC Master**: VAT/EWT code, rate, applicable supplier/business classification and effective dates, based on current authoritative guidance.
4. Maintain suppliers, TINs, VAT status and one or more transaction tax profiles; maintain **Source of Fund** options.
5. Securely distribute School User onboarding credentials.

## Monthly control
1. Open **Transaction Periods**; choose month and targets (each school and/or Division).
2. Open eligible periods; reopening a previously closed period requires a documented reason.
3. Monitor unfinished Drafts, Submitted/Returned items, pending edits and cancellation requests.
4. Close only when the system reports no blockers for the selected target. School and Division periods are independent.

## Review transactions
1. Use the **Division Action Center** or notification bell to locate **Submitted for checking**.
2. Verify source documents, supplier/TIN, transaction origin, date, source of fund, configured ATCs and all computed amounts.
3. Select **Check** on acceptable submissions. For errors, select **Return for Correction** and enter useful remarks.
4. Review pending edits to Checked records against the original frozen values before approval or rejection.
5. Review a school's checked-record cancellation request; maintain reason and approval history. Use **Void** only under approved control procedures.
6. Division-originated transactions have a separate Draft/Checked workflow and reference series. A Division user's own cancellation request must be reviewed by a different authorized Division user.

## Monitoring and reporting
Use dashboards and Reports for filtered, checked-only financial totals where appropriate, CSV exports and month-end reconciliation. BIR encoding/reconciliation status reflects tracking in this application; verify it against the actual BIR workflow. Reports and exports can contain financial/personal identifiers, so apply records-handling controls.

## Accounts
Division Administrators can manage School User accounts and approve eligible School User reset requests, not create/alter other privileged Division Administrators. Approved resets issue a one-time temporary password and require the recipient to change it.

## Monthly sign-off
Confirm pending-review queue is cleared, corrected submissions are checked, funds/ATCs are reconciled, transaction exceptions addressed, BIR actions verified, certificates reviewed and each target month closed only when ready.
